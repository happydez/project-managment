# Фаза 1. Пункт 5. Чёткий коллективный МАИ

Задание: определить наиболее подходящий вариант методом чёткого коллективного МАИ.

Расчёт сделан в книге [concept-selection.xlsx](concept-selection.xlsx):

- лист «МАИ оценки» - матрицы парных сравнений каждого эксперта, их веса и проверка согласованности;
- лист «МАИ» - сводка CR, агрегированные матрицы и глобальные приоритеты.

Все значения на листе «МАИ» считаются формулами по листу «МАИ оценки».

## Исходные данные

Каждый эксперт заполнил 7 матриц парных сравнений по шкале Саати (1-9):

- сравнение критериев C1-C6 между собой по важности (матрица 6 x 6);
- сравнение концепций A1-A4 между собой по каждому из критериев (6 матриц 4 x 4).

В клетке на пересечении строки i и столбца j ставится, во сколько раз элемент строки важнее (лучше) элемента столбца: 1 - одинаково, 3 - умеренно, 5 - существенно, 7 - значительно, 9 - очень сильно, чётные значения промежуточные. Если элемент столбца лучше, ставится обратная дробь (1/3, 1/5 и т. д.). Заполняется только верхний треугольник, нижний считается как обратные значения.

Для MIN-критериев (C2, C6) сравнивается предпочтительность: лучше та концепция, у которой сложность или зависимость от внешних систем меньше.

Сравнения эксперты делали, ориентируясь на свои оценки из [expert-ratings.md](expert-ratings.md), чтобы два метода опирались на одни и те же мнения.

## Порядок расчёта

1. Для каждой матрицы считаются веса методом среднего геометрического: для каждой строки берётся среднее геометрическое её элементов, затем значения нормируются так, чтобы сумма была равна 1.
2. Проверка согласованности. λ_max = сумма по j (сумма элементов столбца j * w_j), индекс согласованности CI = (λ_max - n)/(n - 1), отношение согласованности CR = CI/RI, где RI = 0.90 для n = 4 и RI = 1.24 для n = 6. Матрица считается согласованной при CR < 0.1.
3. Агрегирование. Матрицы четырёх экспертов объединяются в одну поэлементным средним геометрическим (метод AIJ). Среднее геометрическое сохраняет обратную симметричность матрицы: если a_ij = x, то a_ji = 1/x. Для агрегированных матриц так же считаются веса и CR.
4. Глобальный приоритет альтернативы i = сумма по критериям (w_j * p_ij), где w_j - вес критерия из агрегированной матрицы критериев, p_ij - локальный приоритет альтернативы i из агрегированной матрицы по критерию j.

## Проверка согласованности

Все 28 матриц экспертов согласованы, наибольший CR = 0.075 (E2, критерий C6). Агрегированные матрицы согласованы ещё лучше (CR не больше 0.016), так как среднее геометрическое сглаживает отклонения отдельных экспертов.

При первоначальном заполнении у матрицы E4 по критерию C6 было CR = 0.128. Эксперт по своим оценкам сильно разделял концепции по зависимости от внешних систем, и несколько сравнений упёрлись в максимум шкалы 9, из-за чего нарушилась транзитивность. Матрица была пересмотрена: крайние сравнения смягчены (например, A1 с A2: 9 заменено на 5, A3 с A4: 9 на 7), после чего CR = 0.021.

## Выводы

По МАИ первое место занял A2 (0.329), второе - A1 (0.320). Разница всего 0.009, то есть по МАИ эти две концепции практически равны. A3 и A4 заметно отстают.

A2 лучше остальных по четырём критериям: C2 (сложность реализации), C3 (знакомство с областью), C4 (полезность) и C5 (разнообразие работ). A1 лучший по C1 (ясность требований) и C6 (зависимость от внешних систем), а по C2 сильно проигрывает: его локальный приоритет 0.112 против 0.385 у A2. В шкале отношений МАИ эксперты считали A2 проще A1 примерно в 3 раза (в агрегированной матрице 3.2), и при весе C2 около 0.2 это почти полностью съедает преимущество A1 по C1 и C6.

A4 на последнем месте и по МАИ: у него самые низкие приоритеты по C1, C5 и C6.

По нечёткому TOPSIS ([topsis.md](topsis.md)) первым был A1, а A2 - вторым. Сравнение двух методов и причины расхождения разобраны в следующем пункте.
