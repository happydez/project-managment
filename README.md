# Проектный менеджмент - практика

Материалы и результаты пяти фаз практики по предмету «Проектный менеджмент».

| Код | Участник |
|-----|----------|

Коды E1-E4 используются в оценках, где участники выступают экспертами.

## Фазы

| Фаза | Папка | Содержание | Статус |
|------|-------|------------|--------|
| 1. Выбор концепции | `phase-1/` | концепции и критерии, экспертные оценки, нечёткий коллективный TOPSIS, чёткий коллективный МАИ | в работе |
| 2. Распределение работы (мета) | `phase-2/` | декомпозиция работ фазы 3, оценка сложности и предпочтений, задача распределения | не начата |
| 3. Оценка проекта | `phase-3/` | use cases, COSMIC FP, Use Case Points, коллективная экспертная оценка | не начата |
| 4. Прогнозирование (мета) | `phase-4/` | декомпозиция работ фазы 5, трёхточечные оценки, Монте-Карло | не начата |
| 5. Планирование | `phase-5/` | задачи проекта, ресурсы, предшествование, эвристики, календарный план | не начата |

## Порядок работы

Каждый пункт задания делается в отдельной ветке вида `phase-N/<номер>-<пункт>`, например `phase-1/1-concepts`. Когда пункт готов, ветка сливается в `main` через Pull Request.
