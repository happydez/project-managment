# Фаза 2. Пункт 1. Декомпозиция работ фазы 3

Задание: сперва разбить работу фазы 3 на задачи.

Фаза 3 - оценка проекта A1 «Сервис управления системными службами серверов»: use cases, COSMIC Function Points, Use Case Points, коллективная экспертная оценка и выводы. Ниже работа фазы разбита на 18 задач. Оценки сложности и предпочтений, а также распределение по исполнителям появятся в следующих пунктах фазы 2.

## Как разбивали

- Каждый пункт задания фазы 3 даёт одну или несколько задач. Крупные пункты разделены так, чтобы у задачи был один исполнитель и один проверяемый результат.
- 12 use cases разделены на три группы по 4 штуки по смыслу, чтобы их можно было писать параллельно. Номера UC совпадают с предварительным списком в [concepts.md](../phase-1/concepts.md).
- Изучение методов (COSMIC, UCP) вынесено в отдельные задачи: по правилам практики такая работа тоже учитывается.
- Встречи и покер планирования - коллективные задачи, в них участвуют все.

## Что из этого идёт в задачу распределения

- Распределяются только 15 индивидуальных задач. Коллективные (3.1, 3.14, 3.17) выполняют все, поэтому в распределении они не участвуют, им нужен только организатор.
- Связи «после задач» задают порядок выполнения, но не исполнителя, поэтому на само распределение не влияют.
