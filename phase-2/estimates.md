# Фаза 2. Пункт 2. Экспертная оценка трудозатрат

Задание: оценить сложность или трудозатраты задач экспертным путём (пользуясь любыми практиками экспертного оценивания).

Оцениваются 18 задач фазы 3 из [decomposition.md](decomposition.md). Оценки и расчёты - в книге [work-distribution.xlsx](work-distribution.xlsx), лист «Трудозатраты». Ниже те же данные в виде таблиц.

## Как оценивали

Оценивали трудозатраты, а не сложность в баллах: чистое время на задачу в часах с шагом 0.5 часа. Часы удобнее по трём причинам:

- в задаче распределения по ним можно прямо сравнивать и ограничивать нагрузку участников;
- в тех же единицах ведётся учёт фактического времени по задачам;
- оценку потом можно сравнить с фактом.

Экспертами были все четыре участника команды (E1-E4). Метод - Дельфи:

1. Каждый эксперт независимо, не видя чужих оценок, оценил все 18 задач.
2. Оценки свели в одну таблицу и проверили согласованность. Оценки задачи считаются согласованными, если наибольшая отличается от наименьшей не больше чем в 2 раза.
3. По несогласованным задачам эксперты объясняют свои оценки и проводится следующий раунд.
4. Итоговая оценка задачи - медиана оценок экспертов. Медиана выбрана вместо среднего, потому что на неё не влияет одна крайняя оценка.

Для коллективных задач (встречи, покер планирования) эксперт оценивал время одного участника. Трудозатраты такой задачи в человеко-часах равны итоговой оценке, умноженной на число участников.

## Результат

Все 18 задач прошли проверку согласованности в первом раунде: наибольшее отношение макс / мин равно 2.00 (задача 3.6), у остальных задач оно не превышает 1.67. Второй раунд не понадобился.

| Показатель | Значение |
|------------|----------|
| Индивидуальные задачи (15 штук) | 34 ч |
| Коллективные задачи (3 штуки) | 14 чел.-ч, по 3.5 ч на участника |
| Всего по фазе 3 | 48 чел.-ч |
| В среднем на участника | 12 ч |

Что видно из оценок:

- Самые трудоёмкие задачи - use cases «Действия, API и аудит» (3.5 ч), так как в этой группе больше всего негативных сценариев, а также use cases «Серверы и агенты», подсчёт движений данных COSMIC и отчёт (по 3 ч).
- Самые лёгкие - сверка use cases, изучение UCP, расчёт UAW и UUCW и агрегация экспертных оценок (по 1.5 ч).
- Общий объём (48 чел.-ч) близок к фактическим трудозатратам фазы 1 (47.5 чел.-ч).
- Если разделить индивидуальные задачи поровну, на участника придётся 34 / 4 = 8.5 ч. Это ориентир для ограничения нагрузки в задаче распределения.

В задачу распределения идут итоговые оценки 15 индивидуальных задач.
